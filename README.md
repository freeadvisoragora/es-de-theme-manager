## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Theme Catalog** | Browse available ES-DE themes with screenshots and descriptions |
| **One-Click Install** | Download and deploy any theme directly from the manager |
| **Active Theme** | Switch between installed themes from a dropdown with live preview |
| **Backup System** | Back up your current theme before installing a new one |
